# Functional Requirements

This document defines the core functional requirements for the TODO application.

## Core Features

1. The user can create a new task with a required title.
2. The user can optionally add a due date when creating or editing a task.
3. The user can edit an existing task title and due date.
4. The user can mark a task as complete and unmark it back to active.
5. The user can delete a task.
6. The user can view tasks grouped by status (active and completed).
7. The user can sort tasks by due date (earliest first), then by creation time.
8. The user can filter tasks by status (all, active, completed).
9. The user can view overdue tasks clearly identified in the task list.
10. The application persists tasks so they remain available after page refresh.
